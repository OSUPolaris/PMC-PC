# Title: Finding Rogue Planets with Roman
Original Author: Arjun Murlidhar

*Subfield: Astronomy*

*Topics covered: microlensing, rogue planets, single lens model*

*Type of project: data analysis*

## Short Description:
This project is aimed at introducing the mentees to the exciting field of microlensing and its potential to discover free-floating planets (FFPs) in the galaxy. The mentees will first go through some background material to learn the fundamentals of the technique of microlensing. They will then learn how to fit a basic (1 lens 1 source) microlensing model to data by working through a pre-written python notebook. 

In the final part of the project, the mentees will use the code in the notebook to fit a large number of light curves from the 2026 Roman Microlensing Data Challenge (https://rges-pit.org/data-challenge/) and plot the distribution of the event timescales to identify FFP candidates in the data.
