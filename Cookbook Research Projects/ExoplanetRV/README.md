# Title: Exoplanet Detection using the RV Method
Original Author: Angelica Whisnant

*Subfield: Astronomy*

*Topics covered: Exoplanets, Radial Velocity Method*

*Type of project:Data Analysis*

## Short Description:
In this project, the mentee will learn about different methods of exoplanet detection. For this project, the focus is on the radial velocity (RV) method. The mentee will learn python skills on data analysis (working with data files, plotting). The mentee will also learn how to use the RV method to determine properties of an exoplanet orbiting its host star.
