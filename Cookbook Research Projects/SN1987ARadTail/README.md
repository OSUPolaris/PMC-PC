# Title: Understanding the Radioactive Tail of SN 1987A
Original Author: Melanie Zaidel

*Subfield: Astrophysics*

*Topics covered: Supernova lightcurves, radioactive decay*

*Type of project: Data Analysis*

## Short Description:
In this project, the student will learn about radioactivity and supernovae physics and classification in order to calculate determine the radioactive element responsible for electromagnetic emission in the early lightcurve of SN1987A. To do so, the student will be introduced to basic supernova physics, radioactive decay, and fitting a model.
