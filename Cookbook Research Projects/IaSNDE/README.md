# Title: Dark Energy from Type Ia Supernovae
Original Author: Nihar Dalal

*Subfield: Cosmology*

*Topics covered: Supernovae, Cosmology, Dark Energy*

*Type of project: Data Analysis*

## Short Description:
In this project, the student will recreate the analysis by the Supernova Cosmology Project and the High-z Supernova Team that found the first evidence for the accelerating expansion of the universe, and established the existence of Dark Energy. The student will use data from the Union Supernova sample, which contains redshift and distance moduli to several hundred Type Ia supernovae, and fit different cosmological models to the "Hubble plot". The student will learn about simple cosmological models, including LCDM, and various extensions. They will also learn about the distance ladder, and several parameter estimation and fitting techniques including MCMC.
