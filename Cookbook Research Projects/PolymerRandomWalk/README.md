# Title: Random Walks to Model Biological Systems
Original Author: Nils Sommerfeld

*Subfield: Biophysics*

*Topics covered: Random walks, Boltzmann statistics*

*Type of project: Theory*

## Short Description:
In this project we will learn about random walks and how they can be used to model various biological systems. First, we will derive and verify various properties of random walks, in the order of the mentee’s preference. Next, we will make a connection between random walks and polymer configurations, and then briefly introduce Boltzmann statistics and modify a random walk appropriately to solve the problem of polymer configuration under force. This would already give enough deliverables, but if time allows there are various other systems that can be modeled with random walks. The learning objectives of this project are to learn about the model of random walks, how it is connected to real biological systems, and then learning the math of the model and simulating this model in python.
