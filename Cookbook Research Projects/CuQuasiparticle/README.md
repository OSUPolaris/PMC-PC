# Title: Quasiparticle Interference Mapping of Cu(111) Surface
Original Author: Will Koll

*Subfield: Condensed Matter*

*Topics covered: scanning tunnelling microscopy*

*Type of project: Data Analysis*

## Short Description:
In short, the project is to analyze some Scanning Tunneling Microscopy data, and extract the effective mass of electrons in a copper crystal.  It sounds intimidating (especially if the mentor has no condensed matter background), but it doesn't require anything more sophisticated than some basic curve fitting.  The project requires zero coding if the student is willing to use some free, open source analysis software.
